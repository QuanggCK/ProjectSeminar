Java Ngôn Ngữ Lập Trình Java

"Write Once, Run Anywhere" - Ngôn ngữ OOP phổ biến nhất do James Gosling phát triển tại Sun Microsystems (1995).

Giới Thiệu Java

Java là ngôn ngữ lập trình hướng đối tượng, chạy trên JVM (Java Virtual Machine), platform-independent. Java được dùng rộng rãi trong ứng dụng doanh nghiệp, Android, và web backend.

📌 Đặc điểm của Java:
  • Hướng đối tượng hoàn toàn (mọi thứ là Object)
  • Tự động quản lý bộ nhớ (Garbage Collection)
  • Chạy trên mọi nền tảng có JVM
  • Hệ sinh thái thư viện khổng lồ

public class ControlFlow {
    public static void main(String[] args) {
        // if-else
        int diem = 85;
        if (diem >= 90) {
            System.out.println("Xuat sac");
        } else if (diem >= 80) {
            System.out.println("Gioi");
        } else {
            System.out.println("Can co gang");

        // for-each loop

            System.out.println("Dem: " + n);
            n--;
        }
    }
}

Lập Trình Hướng Đối Tượng (OOP)

Class, Constructor & Encapsulation ▼
Java 
class SinhVien {
    // Thuộc tính - Encapsulation (đóng gói)
    private String ten;
    private int tuoi;
    private double diemTB;

    // Constructor
    public SinhVien(String ten, int tuoi, double diemTB) {
        this.ten = ten;
        this.tuoi = tuoi;
        this.diemTB = diemTB;
    }

    // Getter & Setter
    public String getTen() { return ten; }
    public double getDiemTB() { return diemTB; }

    // Phương thức
    public String xepLoai() {
        if (diemTB >= 8.5) return "Gioi";
        if (diemTB >= 7.0) return "Kha";
        if (diemTB >= 5.0) return "Trung binh";
        return "Yeu";
    }

    public void hienThi() {
        System.out.println("Ten: " + ten + ", Tuoi: " + tuoi +
                ", Diem: " + diemTB + ", Xep loai: " + xepLoai());
    }
}

public class Main {
    public static void main(String[] args) {
        SinhVien sv = new SinhVien("Nguyen Van A", 20, 8.7);
        sv.hienThi();
    }
}
Ten: Nguyen Van A, Tuoi: 20, Diem: 8.7, Xep loai: Gioi
Kế thừa (Inheritance) & Đa hình (Polymorphism) ▼
Java 
// Lớp cha (Superclass)
class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    public void speak() {
        System.out.println(name + " makes a sound");
    }
}

// Lớp con (Subclass) - Override phương thức
class Dog extends Animal {
    public Dog(String name) {
        super(name);  // Gọi constructor lớp cha
    }

    @Override
    public void speak() {
        System.out.println(name + " says: Woof!");
    }
}

class Cat extends Animal {
    public Cat(String name) {
        super(name);
    }

    @Override
    public void speak() {
        System.out.println(name + " says: Meow!");
    }
}

public class Main {
    public static void main(String[] args) {
        // Đa hình - biến lớp cha chứa đối tượng lớp con
        Animal[] animals = {
            new Dog("Buddy"),
            new Cat("Kitty"),
            new Animal("Unknown")
        };

        for (Animal a : animals) {
            a.speak();  // Gọi phương thức tùy theo kiểu thực
        }
    }
}
Buddy says: Woof! Kitty says: Meow! Unknown makes a sound

Interfaces

Interface là "hợp đồng" mà class phải tuân thủ. Một class có thể implement nhiều interfaces.

Java 
// Khai báo Interface
interface Drawable {
    void draw();           // Phương thức trừu tượng
    double getArea();       // Phương thức trừu tượng
}

interface Resizable {
    void resize(double factor);
}

// Class implement nhiều interfaces
class Circle implements Drawable, Resizable {
    private double radius;

    public Circle(double r) { radius = r; }

    @Override
    public void draw() {
        System.out.println("Drawing circle, r = " + radius);
    }

    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }

    @Override
    public void resize(double factor) {
        radius *= factor;
        System.out.println("Resized to r = " + radius);
    }
}

public class Main {
    public static void main(String[] args) {
        Circle c = new Circle(5);
        c.draw();
        System.out.println("Area: " + String.format("%.2f", c.getArea()));
        c.resize(2);
        System.out.println("New area: " + String.format("%.2f", c.getArea()));
    }
}
Drawing circle, r = 5.0 Area: 78.54 Resized to r = 10.0 New area: 314.16

Collections Framework

Java 
import java.util.*;

public class CollectionsDemo {
    public static void main(String[] args) {
        // === ArrayList ===
        ArrayList<String> names = new ArrayList<>();
        names.add("An");
        names.add("Binh");
        names.add("Cuong");
        Collections.sort(names);
        System.out.println("ArrayList: " + names);

        // === HashMap ===
        HashMap<String, Integer> scores = new HashMap<>();
        scores.put("An", 85);
        scores.put("Binh", 92);
        scores.put("Cuong", 78);

        System.out.println("\nDiem sinh vien:");
        for (Map.Entry<String, Integer> entry : scores.entrySet()) {
            System.out.println(entry.getKey() + ": " + entry.getValue());
        }

        // === HashSet ===
        HashSet<Integer> uniqueNums = new HashSet<<>>(Arrays.asList(1,2,3,2,1));
        System.out.println("\nHashSet (unique): " + uniqueNums);
    }
}
ArrayList: [An, Binh, Cuong] Diem sinh vien: An: 85 Binh: 92 Cuong: 78 HashSet (unique): [1, 2, 3]

Xử Lý Ngoại Lệ (Exception Handling)

Java 
public class ExceptionDemo {
    public static int chia(int a, int b) throws ArithmeticException {
        if (b == 0) {
            throw new ArithmeticException("Khong the chia cho 0!");
        }
        return a / b;
    }

    public static void main(String[] args) {
        try {
            int result = chia(10, 3);
            System.out.println("10 / 3 = " + result);

            result = chia(10, 0);  // Gây exception!
            System.out.println("Dong nay khong chay");

        } catch (ArithmeticException e) {
            System.out.println("Loi: " + e.getMessage());

        } finally {
            System.out.println("Block finally luon chay!");
        }
    }
}
10 / 3 = 3 Loi: Khong the chia cho 0! Block finally luon chay!
