📦 Biến (Variables) ▼

Biến là vùng nhớ được đặt tên để lưu trữ dữ liệu. Mỗi biến có tên, kiểu dữ liệu và giá trị.

📌 Quy tắc đặt tên biến: Bắt đầu bằng chữ cái hoặc dấu gạch dưới, không chứa khoảng trắng, phân biệt chữ hoa/thường.

Trong ngôn ngữ C:

C 
#include <stdio.h>

int main() {
    int tuoi = 20;          // Biến số nguyên
    float diemTB = 8.5;    // Biến số thực
    char xepLoai = 'A';    // Biến ký tự

    printf("Tuoi: %d\n", tuoi);
    printf("Diem TB: %.1f\n", diemTB);
    printf("Xep loai: %c\n", xepLoai);
    return 0;
}
Tuoi: 20 Diem TB: 8.5 Xep loai: A

Trong ngôn ngữ Python:

Python

➕ Toán Tử (Operators) ▼

Toán tử là các ký hiệu thực hiện phép toán trên dữ liệu.

💡 Các loại toán tử: Số học (+, -, *, /), So sánh (==, !=, <, >), Logic (&&, ||, !), Gán (=, +=, -=)
Java 
public class Operators {
    public static void main(String[] args) {
        int a = 10, b = 3;

        // Toán tử số học
        System.out.println("a + b = " + (a + b));  // 13
        System.out.println("a - b = " + (a - b));  // 7
        System.out.println("a * b = " + (a * b));  // 30
        System.out.println("a / b = " + (a / b));  // 3
        System.out.println("a % b = " + (a % b));  // 1

        // Toán tử so sánh
        System.out.println("a > b: " + (a > b));    // true
        System.out.println("a == b: " + (a == b)); // false
    }
}
a + b = 13 a - b = 7 a * b = 30 a / b = 3 a % b = 1 a > b: true a == b: false
🔀 Câu Điều Kiện (if / else) ▼

Câu điều kiện cho phép chương trình đưa ra quyết định dựa trên điều kiện đúng/sai.

C 
#include <stdio.h>

int main() {
    int diem = 75;

    if (diem >= 90) {
        printf("Xuat sac!\n");
    } else if (diem >= 70) {
        printf("Kha!\n");
    } else if (diem >= 50) {
        printf("Trung binh!\n");
    } else {
        printf("Can co gang hon!\n");
    }
    return 0;
}
Kha!

🔁 Vòng Lặp (Loops) ▼

Vòng lặp cho phép thực hiện một khối lệnh lặp đi lặp lại nhiều lần.

Vòng lặp for:

Java 
public class LoopDemo {
    public static void main(String[] args) {
        // Vòng lặp for
        for (int i = 1; i <= 5; i++) {
            System.out.println("Lan lap: " + i);
        }

        // Vòng lặp while
        int count = 0;
        while (count < 3) {
            System.out.println("Count: " + count);
            count++;
        }
    }
}
Lan lap: 1 Lan lap: 2 Lan lap: 3 Lan lap: 4 Lan lap: 5 Count: 0 Count: 1 Count: 2
⚡ Hàm (Functions) ▼

Hàm là khối code được đặt tên, có thể tái sử dụng. Hàm nhận đầu vào (tham số) và trả về kết quả.

C++ 
#include <iostream>
using namespace std;

// Hàm tính tổng hai số
int tinhTong(int a, int b) {
    return a + b;
}

// Hàm tính giai thừa (đệ quy)
int giaiThua(int n) {
    if (n <= 1) return 1;
    return n * giaiThua(n - 1);
}

int main() {
    cout << "Tong: " << tinhTong(5, 3) << endl;
    cout << "5! = " << giaiThua(5) << endl;
    return 0;
}
Tong: 8 5! = 120
📊 Mảng (Arrays) ▼

Mảng là cấu trúc dữ liệu lưu trữ nhiều phần tử cùng kiểu trong bộ nhớ liên tiếp.

C 
#include <stdio.h>

int main() {
    int diem[5] = {85, 92, 76, 88, 95};
    int tong = 0;

    for (int i = 0; i < 5; i++) {
        printf("diem[%d] = %d\n", i, diem[i]);
        tong += diem[i];
    }
    printf("Trung binh: %.1f\n", (float)tong / 5);
    return 0;
}
diem[0] = 85 diem[1] = 92 diem[2] = 76 diem[3] = 88 diem[4] = 95 Trung binh: 87.2
🎯 Con Trỏ (Pointers) - C/C++ ▼

Con trỏ là biến lưu trữ địa chỉ bộ nhớ của biến khác. Đây là khái niệm đặc trưng của C/C++.

⚠️ Lưu ý: Con trỏ là khái niệm khó. Sử dụng sai có thể gây lỗi segmentation fault hoặc memory leak!
C 
#include <stdio.h>

int main() {
    int x = 42;
    int *ptr = &x;  // ptr lưu địa chỉ của x

    printf("Gia tri x: %d\n", x);
    printf("Dia chi x: %p\n", &x);
    printf("Gia tri ptr: %p\n", ptr);
    printf("Gia tri tai ptr: %d\n", *ptr);

    *ptr = 100;  // Thay đổi giá trị qua con trỏ
    printf("x sau khi thay doi: %d\n", x);

    return 0;
}
Gia tri x: 42 Dia chi x: 0x7ffd5e8c3abc Gia tri ptr: 0x7ffd5e8c3abc Gia tri tai ptr: 42 x sau khi thay doi: 100
🏗️ Lập Trình Hướng Đối Tượng (OOP) ▼

OOP là phương pháp lập trình dựa trên khái niệm "đối tượng" chứa dữ liệu và phương thức.

4 trụ cột OOP: Đóng gói (Encapsulation), Kế thừa (Inheritance), Đa hình (Polymorphism), Trừu tượng (Abstraction).
Python 
class DongVat:
    def __init__(self, ten, tuoi):
        self.ten = ten
        self.tuoi = tuoi

    def gioi_thieu(self):
        print(f"Toi la {self.ten}, {self.tuoi} tuoi")

class Cho(DongVat):   # Kế thừa từ DongVat
    def __init__(self, ten, tuoi, giong):
        super().__init__(ten, tuoi)
        self.giong = giong

    def sua(self):
        print(f"{self.ten} sua: Gau gau!")

# Tạo đối tượng
dog = Cho("Buddy", 3, "Golden")
dog.gioi_thieu()
dog.sua()
Toi la Buddy, 3 tuoi Buddy sua: Gau gau!

Hướng Dẫn Cài Đặt Công Cụ

🔵 Cài đặt cho C / C++

Cài đặt GCC (MinGW) ▼
  1. Truy cập trang MinGW-w64
  2. Tải phiên bản phù hợp với hệ điều hành (Windows 64-bit)
  3. Giải nén vào thư mục C:\mingw64
  4. Thêm C:\mingw64\bin vào biến môi trường PATH
  5. Mở CMD, gõ gcc --version để kiểm tra
⬇️ Tải MinGW
Cài đặt Code::Blocks ▼
  1. Truy cập codeblocks.org
  2. Tải bản codeblocks-xx.xx-mingw-setup.exe (có kèm compiler)
  3. Chạy file cài đặt, chọn Full Installation
  4. Mở Code::Blocks, tạo project C/C++ đầu tiên
⬇️ Tải Code::Blocks
Cài đặt Dev-C++ ▼
  1. Truy cập SourceForge - Dev-C++
  2. Tải phiên bản mới nhất
  3. Cài đặt với các tùy chọn mặc định
  4. Mở Dev-C++, vào File → New → Source File
⬇️ Tải Dev-C++

🟠 Cài đặt cho Java

Cài đặt JDK (Java Development Kit) ▼
  1. Truy cập Oracle JDK hoặc Adoptium (OpenJDK)
  2. Tải JDK cho hệ điều hành của bạn
  3. Chạy cài đặt, ghi nhớ thư mục cài
  4. Thêm JAVA_HOME và bin vào PATH
  5. Mở CMD, gõ java --version và javac --version
⬇️ Tải OpenJDK
Cài đặt IntelliJ IDEA ▼
  1. Truy cập JetBrains IntelliJ IDEA
  2. Tải bản Community (miễn phí) hoặc Ultimate
  3. Cài đặt theo hướng dẫn
  4. Mở IntelliJ, cấu hình JDK đã cài
  5. Tạo project Java đầu tiên
⬇️ Tải IntelliJ IDEA

🟢 Cài đặt cho Python

Cài đặt Python ▼
  1. Truy cập python.org
  2. Tải phiên bản Python mới nhất
  3. Quan trọng: Tick ✅ "Add Python to PATH" khi cài đặt
  4. Mở CMD, gõ python --version để kiểm tra
  5. Gõ pip --version để kiểm tra pip
⬇️ Tải Python
Cài đặt VS Code ▼
  1. Truy cập code.visualstudio.com
  2. Tải phiên bản cho hệ điều hành
  3. Cài đặt VS Code
  4. Mở VS Code, vào Extensions (Ctrl+Shift+X)
  5. Cài extension "Python" của Microsoft
  6. Cài extension "Code Runner" để chạy code nhanh
⬇️ Tải VS Code
